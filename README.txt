INTERNSHIP TASK MANAGEMENT DASHBOARD

FILES
- app.py: Streamlit dashboard source code
- Internship_Task_Management.xlsx: intern and task workbook

HOW TO RUN (Windows)
1. Extract this ZIP file.
2. Open the extracted Internship_Task_Management_Project folder in VS Code.
3. Open Terminal in that folder.
4. Install dependencies:
   python -m pip install streamlit pandas openpyxl
5. Run the dashboard:
   python -m streamlit run app.py
6. Streamlit will open the dashboard in your browser.

IMPORTANT
- Keep app.py and Internship_Task_Management.xlsx in the same folder.
- Close the Excel workbook before assigning tasks or updating reviews.
- The workbook's Intern Details sheet should contain the column headings used by the app.
